## 1. 要解决的问题

1. **没有水墨画风。** 仓里 11 个设计 skill 有铅笔手绘(graphite)、新拟态、玻璃、发布会等,
   没有中国水墨。诗词、武侠、山水、四季这类题材,以及想做出东方气质的技术讲解、发布会、界面,目前没有可用的风格。
2. **每做一个设计 skill,方法都要重新摸索一遍。** 4 月的 apple / anthropic 按「设计 token + 模板」写;
   8 月的 primer 加了拆解方法和接入清单;10 月的 graphite 又换成「定死几样 + 其余放开 + 出图模型分工 + 口味学习」。
   这些经验散在各自的设计书和提交里,没有一处写全。
3. **接入清单只有文字,漏了没人发现。** primer 设计书 §8 列了加一个设计 skill 要改的十几处
   (检查脚本注册、首页、README、critic 配置……),并在 §8.5 记录了上一个 skill(atelier)漏掉的一串。
   没有脚本能查「这次接全了没有」。
4. **「越用越懂你」只有 graphite 有,而且只学 graphite 自己。** 口味参数表写死在
   `skills/graphite-design/assets/taste.js` 里;同一个人在别的风格里说过的「字太小」,其他风格不知道;
   做技术图和做壁纸的口味混在一起记。

## 4. 功能需求

优先级:**必须** = 该阶段不完成不算交付;**应有** = 该阶段尽量做,可顺延一个阶段。

### 4.1 风格规则(`inkwash-design/SKILL.md` 与 `references/`)

| 编号 | 需求 | 优先级 | 设计 | 阶段 |
|---|---|---|---|---|
| R-F01 | SKILL.md 写明「定死的五样」(纸、水做的墨和色、提按笔触、留白、印和书法字),每样都有「怎么做」和「没有它会怎样」两栏 | 必须 | §3 | P2 |
| R-F02 | SKILL.md 写明「放开的」:版式、构图、设色方式、动画方式、载体、谁来画都不限定;图例是例子不是模板 | 必须 | §3 | P2 |
| R-F03 | 四种设色方式都算水墨,各有色值和适用场景:纯水墨、浅绛、青绿、彩墨 / 没骨 | 必须 | §3.3 | P2 |
| R-F04 | 动笔前的「场景四问」(在哪看、读者要得到什么、动不动多长、有没有必须准确的东西)写进 SKILL.md,放在画法之前 | 必须 | §4 | P2 |
| R-F05 | 场景表覆盖 5 组(技术图、页面与界面、发布会、叙事画面、静赏),每组给出优先什么、留白、设色、笔法和字、动画、谁来画、常见坑 | 必须 | §4 | P2 |
| R-F06 | 深色版用磁青纸配泥金线,另画不反相;位图要另出一张,不许把浅色图反相 | 必须 | §3.1 | P2 |
| R-F07 | `references/material.md` 给出全部色值(纸、五档墨色、颜料、印泥,各分浅深)和每个值的理由;色值的权威在 CSS,两处冲突以 CSS 为准 | 必须 | §3 | P2 |
| R-F08 | `references/recipes.md` 按图例分类写画法要点:这类图要讲清什么、怎么画、动起来动什么、对应哪个源文件 | 必须 | §8 | P3 |
| R-F09 | 踩过的坑写成表(现象、原因、怎么办),开发过程中遇到一条记一条 | 必须 | — | P2–P5 |

## 6. 不做的事(本轮)

- 不改造现有 10 个设计 skill(水墨上线 GitHub 之后单独规划,按方法的两档标准)
- 不把画笔代码做成多个风格共用(graphite 的铅笔和水墨的毛笔材料不同);导出脚本先复制一份,第三个风格也要用时再抽成共用
- 不做照片级写实画面,不做 3D
- 位图不追求可复现,不做自动批量重画
- 口味学习不上传、不跨机器同步

## 9. 用到的词

| 词 | 意思 |
|---|---|
| 定死的几样 | 一个画风里不能变的东西;少一样就不是这个画风了 |
| 场景组 | 按「读者要得到什么」把用途分成的 5 组,口味也按组分开记 |
| 择优录取 | 同一题目代码画一版、出图模型画一版,并排比较后选好的 |
| 出图模型 | 根据文字描述生成位图的模型,本仓用的是 Codex CLI 调 `gpt-6-astra` |
| 口味日志 | 记下每次挑选、评价、参考图、审查意见的本机文件,口味由它算出来 |
| 注册点 | 加一个新设计 skill 时仓里要同步修改的位置(检查脚本、名册、首页、README 等) |
| 小样 | 正式开工前验证可行性的一次性试做,验证完就丢 |
| 磁青纸、泥金 | 古代写经用的深靛蓝纸和金粉调成的颜料;本 skill 深色版的纸和线 |
| 飞白 | 毛笔含墨少、走得快时,笔画里露出纸白的丝状空隙 |
| 浅绛、青绿 | 两种传统设色:浅绛是墨加淡赭石和花青;青绿用石青、石绿,颜色重 |
