D · Execution contextsD · 运行与调度关系

Bands are contexts, ordered by what preempts what — the top band interrupts everything below it. The property the reader actually needs is can this code sleep, so the two bands where it cannot are ringed. Getting this wrong does not fail at build time; it deadlocks under load, weeks later.带是上下文，按谁打断谁排 —— 最上面那条打断它下面的一切。读者真正需要的属性是这段代码能不能睡眠，所以不能睡的那两条带描了圈。这件事搞错不会在编译时报错，会在跑满负载的时候死锁，而且是几周以后。

G · Stack overflowG · 栈溢出

The stack grows downward into a fixed allocation, so the address gutter runs the same way the memory map does. The ringed cell at the bottom is what a single oversized local array runs into. Overwriting that one leaves you with a crash that has no backtrace at all, which is why an overflow usually looks like a corrupted, unrelated panic.栈是往下长的，长进一块固定大小的空间里，所以左边那列地址和内存布局图同一个方向。底下描圈那一格，就是一个过大的局部数组会撞上的东西。踩掉它，你拿到的崩溃连回溯都打不出来 —— 所以栈溢出看起来通常像一个不相干的、内容被踩烂的 panic。

H · Two stacks, two budgetsH · 中断栈和进程栈

Interrupt context does not borrow the process stack — on arm64 it runs on its own, smaller one. That is the real reason a hardirq handler must stay flat: not style, not latency, but a budget that is often half the size and has nothing to do with the thread that got interrupted.中断上下文不是借用进程的栈 —— 在 arm64 上它跑在自己那块更小的栈上。这才是硬中断处理函数必须写得扁的真实原因：不是风格问题，不是延迟问题，是一块常常只有一半大、而且和被打断的那个线程毫无关系的预算。

L · Why it fails at that lineL · 为什么卡在这一行

The other figures on this page draw what the software looks like. This one draws why one specific thing fails at one specific line — so every level carries a file:line you can jump to, and the level that decides the outcome carries the source line itself, not a description of it. A description would lose the difference between return 0 and return -EINVAL, and that difference is usually the whole finding. A level whose line number cannot be known says why it cannot — sunken deeper, because that is what depth means everywhere else here.这一页别的图画的是软件长什么样。这一张画的是为什么某一件事卡在某一行 —— 所以每一层右边都挂着能跳过去的 file:line，而决定结局的那一层贴的是代码原文，不是对它的描述。描述会丢掉 return 0 和 return -EINVAL 的区别，而那个区别常常就是全部结论。拿不到行号的那一层要写为什么拿不到 —— 它凹得更深，因为「凹 = 够不到」在这一页从头到尾就是这个意思。
