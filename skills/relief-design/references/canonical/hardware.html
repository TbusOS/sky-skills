Seven hardware diagrams, drawn in relief七种硬件框图，用凹凸画出来

Every shape on this page carries meaning. Raised is a thing that exists; sunken is a place you cannot reach, a condition, or a channel cut into the surface. Nothing here is decoration — if a block is pressed in, that is the diagram telling you something.这一页上每个形状都有意思。凸起是一个存在的东西；凹陷是你够不到的地方、一个条件、或者刻进面料的一道槽。没有一处是装饰 —— 一块凹进去，是图在告诉你一件事。

D · IP block diagramD · IP 内部框图

Groups sit in sunken wells, modules are raised blocks inside them — a well says these belong together, a block says this is one thing. The bus is a sunken rail: masters attach above it, slaves below. That is the reading convention; break it and every reader has to trace each line to find who initiates a transfer.分组用凹陷的槽装，模块用凸起的块摆进去——槽是「这几个归一起」，块是「这是一个东西」。总线画成一条凹槽轨：主设备接在轨上方，从设备接在下方，这是读图的约定，不按这个摆，看图的人得逐条线追才知道谁发起访问。

Terms used above上面用到的术语

A diagram that needs a word the reader does not have is not a diagram, it is a quiz. Every term below appears somewhere on this page.一张图要是用了读者没有的词，那不是图，是考试。下面每个词在这页上都出现过。

取数 · fetch
the display controller issues its own bus reads to pull a frame out of memory — the CPU does not copy it there.显示控制器自己发起总线读，把一帧像素从内存搬进来。不是 CPU 拷贝给它的。
物理地址 · physical address
the address that actually appears on the bus. Most addresses in kernel code are virtual; page tables map between them.硬件总线上真实的地址。内核代码里看到的多数是虚拟地址，两者靠页表对应。
一致性 · coherency
when several masters each hold a cache, keeping what they see of the same memory identical. Without it you flush caches by hand.多个主设备各有缓存时，保证它们看到的同一块内存内容相同。做不到就得手工刷缓存。
突发 · burst
one bus transaction carrying several beats of data instead of one address per beat. Fetching a whole frame relies on it.一次总线事务连续搬多拍数据，而不是一拍一个地址。取整帧像素靠的就是它。
片上 SRAM · on-chip SRAM
a small memory inside the chip, usable the moment power is up. Early boot code runs here because DDR is not trained yet.做在芯片里的一小块内存，上电就能用。DDR 还没训练好之前，早期代码只能跑在这。
设备树 · device tree
a text file describing what hardware is on the board and which address range each piece owns; the kernel reads it at boot.一份描述板上有哪些硬件、各自占哪段地址的文本文件，内核启动时读它。
门控 · clock gate
a switch deciding whether this clock branch continues downstream. With it closed the modules below simply do not run.一个开关，决定这一支时钟往不往下走。关着的时候下游模块整个不工作。
分频 · divider
divides a clock down to a lower frequency. One PLL usually feeds several parallel branches at different rates.把时钟频率整除成更低的一档。一个 PLL 常常并联出好几路不同频率。
位域 · bitfield
a register's 32 bits cut into runs, each run controlling one thing.把一个寄存器的 32 位切成几段，每段各管一件事。
自清 · self-clearing
writing 1 triggers an action and the hardware clears the bit itself, so it always reads back 0.写 1 触发一个动作，硬件做完自己把这位清回 0。所以读回来永远是 0。
