# 画法 —— 数据流怎么画才看得懂

这份是这套东西最值钱的部分。渲染好看只解决"像不像"，这份解决"看不看得懂"。

## 三条铁律

用户三轮反馈打出来的，每条都是推翻重做换来的：

### 1. 数据必须有形状，不能是"点在线上滑"

一个光点从 A 滑到 B，只说明"有东西过去了"，没说明搬的是什么。**给数据一个能读出含义的形状**：

| 概念 | 画成什么 | 原语 |
|---|---|---|
| 一个 32 位字 | 一行 32 个亮/暗格子 | `wordRow` |
| 一条缓存行 | 8×4 的位块 | `tileAlong` |
| 一条命令 / 一条指令 | 一张卡（底板 + 三条线） | `cardObj` / `tokenAlong` |
| 一个像素 | R/G/B 三行各 8 位 | `wordRow` ×3 |
| 一片帧缓冲 | 像素格网 | `gridObj` |
| 一条总线 | **n 根并行导线**，不是一条线 | `wires` |
| 一个包 | 光球 | `orb` / `packets` |

反例：站 7 早期版本是"一条细线 + 一串点"，用户原话「完全看不出是数据是怎么搬运的」。
正例：每颗颗粒到 die 之间画 32 根走线，每拍一行 32 个格子整排前进，12 束同一拍到达。

### 2. 要画芯片**内部**，不是板级

板级只能讲"这颗连那颗"。原理在 die 里面。把 die 做成一座**城**：

```
地面   逻辑块(SM / 缓存片 / 控制器 / IO)，低饱和灰蓝，不发光
架空   铜色轨道 = 互连总线，立在铜柱上，路口有路由节点，每块有匝道
轨上   数据按拍走
```

**架空是真实结构，不是比喻** —— 芯片里晶体管在最底层，上面叠十几层铜金属层专门走线。
说明卡里要点破这一句，读者才知道你不是在打比方。

**网格还是单条干道？**
- 几十个同构单元、访问模式相似（GPU 的 SM）→ 一条粗**交叉开关**干道
- 十几种异构模块、脾气各不同（手机 SoC）→ **3×3 网格 NoC**，维序路由（先横后竖）

### 3. 按拍走，可暂停单步

全局时钟 `CLK`（拍），`tick()` / `phase()`。每站的数据流写成"第几拍在干什么"的状态机：

```js
const tk=tick(), ph=phase(), step=tk%8, u=ph;
if(step<2){ /* ①请求上总线 */ }
else if(step<3){ /* ②L2 未命中(标红) */ }
...
FLOW.live.mem = `第 ${step+1}/8 拍 · <b>${stage}</b>`;
```

**延迟就是路程** —— 让计数器跟着走的距离涨（寄存器 1 → L1 30 → L2 200 → 显存 500），
读者自己就数出来了，比写一句"显存很慢"有用得多。

## 分层：为什么叠加层要单独一个缓冲

写实底层靠**累积收敛**（相机静止后叠 200 帧）。流动的东西进了累积会被平均成一条拖影。
所以叠加层每个显示帧**单独画**到自己的 HDR 缓冲，深度复用 G-buffer 的、只测不写，
再和累积结果相加后一起进泛光。

副作用是好的：录视频时底图只需在进站时算一次，之后每帧只重画叠加层 → 一帧几毫秒。

## 三套网格，别混用

| 网格 | 用在 | 为什么不能换 |
|---|---|---|
| `box` 圆角盒 bevel 0.08 | 发光垫片、丝带 | — |
| `orb` 圆角盒 bevel 0.5 seg5 | 光球、包、粒子 | 用 box 会变花皮足球（26 个面各自算边缘发光） |
| `flat` bevel 0.002 | 像素格、位格 | 用 box 非等比缩放后角上留黑点 |

## 常用套路

**一次访存走完全程**（62 号站 8，最能讲清"总线"的一站）：
请求带地址上轨 → 哈希选到某一片缓存 → 未命中标红 → 转控制器 → 出片外 →
颗粒沿 n 根线连发 → 控制器拼成缓存行 → 沿原路回。8 拍一轮。

**分支发散**（62 号站 10）：调度器飞出一张指令卡 → 到通道上方裂成 n 份落下 →
遇到 `if` 时一半通道头顶打红叉 → 拍数计数器当场从 3 拍变 6 拍。

**逐级未命中**（62 号站 11）：同一个请求一级级往远走，计数器跟着路程涨。

**层叠剖面里的光路**（62 号站 15 / 63 号站 11）：光球带一根**偏振方向短棒**，
每过一层棒的角度变一次。⚠ 光柱要走在各层**暴露的前沿之外**，否则被夹在层里看不见。

**背景流量**：主干上一直有别的单元的数据在跑（`noiseTraffic`），
不然总线看着像只有一个人在用。
