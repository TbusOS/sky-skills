# 镜头配方

`cam = { tgt, az, el, dist, fov, ap, focus, fy, ex }`
- `ap` = 光圈半径(世界单位),0 = 全清晰
- `focus` = `'point'`(焦平面垂直视线,经典微距)/ `'plane'`(移轴,焦平面贴 y=fy 的水平面)
- `ex` = 曝光

| 类型 | 用途 | 参数 | 对焦 |<!-- bw-ok:对焦=相机对焦,摄影术语 -->
|---|---|---|---|
| **微距** | 看单个元件的材质和丝印 | fov 26 · dist ≈ 物体 3~4 倍 · ap 0.10~0.16 | `point`。浅景深是有意的 |
| **整板俯视** | 看布局和元件密度 | fov 26 · el 0.8~0.9 · ap 0.30~0.45 | `plane`,fy = 板面高度。**必须移轴**,否则只有中间一条带清晰 |
| **棚拍单体** | 单个封装/模块 | fov 24 · el 0.3~0.4 · ap 0.25~0.35 | `plane` |
| **低角掠射** | 看锡球、焊点、层叠 | fov 30 · el 0.05~0.12 · ap 0.15~0.25 | `plane`,fy 略低于物体 |
| **城内俯瞰** | die 内部总线全貌 | fov 26 · el 0.6~0.8 · dist 250~450 · ap 0.22~0.30 | `plane`,fy = 轨面高度 |
| **剖面正对** | 封装/屏幕分层 | fov 26 · el 0.13~0.26 · az 正对切面 | `point`,ap 0.08~0.16 |

## 定机位的顺序(别乱试)

1. **先定要讲什么**:这一站的主体是哪几个部件,它们的世界坐标包围盒多大
2. **再定张角**:可视宽 = 2·dist·tan(fov/2)·aspect,先让包围盒装得下
3. **最后避开面板**:tgt 沿「远离相机」方向推 20~30,把主体从左下的说明卡上抬走
4. **一次试三组**,别一组一组改文件重开 —— `scripts/try_cameras.mjs`

面板占哪几块、以及各种取景翻车的修法,见 `pitfalls.md` 的「取景」一节。

## 站点切换

相机在站点间飞用 1.7s 三次缓动;`dist` 走**指数插值**(线性会先冲远再拉回);
方位角取最短弧(差值归一到 ±π)。飞行中单采样预览,停下后开始累积。

## 标签

HTML 元素按 3D 锚点投影定位 + SVG 引线。`dy` 控制标签相对锚点的偏移,
**多个标签挤在一起时靠 dy 拉开**(正值放锚点下方)。
支持 `live:'键名'` 接实时文字,每帧从 `FLOW.live[键名]` 取。
