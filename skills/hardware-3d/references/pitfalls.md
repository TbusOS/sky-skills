# 踩过的坑

每条都是实际卡住过的,带现象和修法。

## 渲染

| 现象 | 原因 | 修法 |
|---|---|---|
| 黑塑封芯片顶面是灰的,调材质颜色没用 | 柔光箱强度太高(16),把 4% 反射率的塑料打爆了 | 主光降到 6~7,曝光相应调 |
| 全画面发软,焦点上也软 | 亚像素抖动用了 ±0.5px 均匀分布,200 帧平均 = 1px 盒式模糊 | 改高斯 σ≈0.32px |
| 斜俯视只有中间一条带清晰 | 焦平面垂直视线,板面与它成角 | 移轴:薄透镜 = 平移 + 剪切,焦平面法线任取 |
| 剖切后是个空心盒 | discard 只删了正面,里面没东西 | 在剖切面贴一块**断面盖板**(标记位 iExt.y=2,顶点着色器里 x 跟 uCutX 走),按层画剖面纹理 |
| 光球变成花皮足球 | 用圆角盒当光球,26 个面各自算边缘发光 | 光球单独一套网格,着色 `pow(ndv,1.6)` |
| 屏幕像素格角上有黑点 | 圆角盒非等比缩放后圆角变形 | 像素格用**无圆角**的平片网格(bevel 0.002) |
| 画面看着正常但焊点少了一大半 | 实例缓冲 maxInst 开小了,bufferSubData 越界(GL 0x501),之后每帧 drawElementsInstanced 越界(0x502) | `uploadInst` 里加容量断言,超了当场报错 |
| 顶点/片元着色器链接失败 | 同名 uniform 精度不一致(mediump vs highp) | 两边都写 highp |
| 变量名报保留字 | GLSL 里 `gl_` 是保留前缀 | 换名 |

## 建模

| 现象 | 修法 |
|---|---|
| 锡球埋在板子里 | 封装组整体抬高一个球半径,球心留在板面和基板之间 |
| 显示器把画面挤爆 | 按真实比例显示器是显卡的 3.6 倍,缩到六成才装得下 |
| 光柱被夹在层里看不见 | 分层剖面的光路要走在每层**暴露的前沿之外**(该层前边缘再往前几个单位) |
| 细节看不见 | 轨上的数据块要给底下垫一层淡光,远看才有形 |

## 工程

| 现象 | 修法 |
|---|---|
| 补丁脚本前面 print 了一堆 OK,文件却没变 | python 批量替换里任何一个 assert 失败 → 整份不落盘。要么一次成功要么全重跑;**改完必须 grep 回读** |
| 删了几个分支后 buildFlow 整个不执行 | 首个分支必须是 `if` 不是 `else if` |
| headless 截图全黑 | playwright 要带 `--enable-gpu --use-angle=metal`(macOS) |
| 批量出图时,头两站正常、之后全是纯黑 | 渲染分辨率太高(2400×1500 以上)时连续多站跑累积采样会渲不出东西,而 `isContextLost()` 仍返回 false,不会报错。**批量出图固定用 1280×800 @dpr1.5(1920×1200)**,并在每张后读一次中心像素自检 |
| 光看单帧判断不了动画在不在动 | 同一站截相隔 0.7s 的两帧对比(`shoot-motion.mjs` 那种做法) |
