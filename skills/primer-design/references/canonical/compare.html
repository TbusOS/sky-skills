HTTP vs HTTPS: what's the difference? HTTP 和 HTTPS，
差在哪？

No tech background needed. This page explains it in about three minutes. 不需要任何网络基础。这一页大约 3 分钟讲明白。

What are these two? 这俩是什么？

HTTPHTTP the mail rules of the web — sent exactly as written 给网页送信的一套规矩：写什么，路上就是什么
HTTPSHTTPS the same rules, one extra step: sealed before it travels 同一套规矩，多一道工序：内容先封起来，再上路

HTTP and HTTPS are the same delivery rules, with one difference: whether the content is sealed. HTTP 和 HTTPS 是同一套送信规矩，差别只有一件事：内容封不封。

It's like…就像……

Write on a postcard and every pair of hands can read it. Seal it in an envelope and only the receiver can open it. 在明信片背面写话，经手的人都能看到。装进密封信封，就只有收件人拆得开。

What's the same? 它们哪里一样？

Same road, same mailing steps, same delivered page — the address differs by one letter: s. 路一样，寄的步骤一样，送到的页面也一样——网址只差一个字母 s。

Where's the difference? 差别在哪儿？

The difference is all on the road: HTTP travels bare and readable; HTTPS travels sealed. 差别全在路上：HTTP 的内容裸着走，经手的都能看；HTTPS 封着走，只能看到乱码。

How do you tell which one you're on? 怎么分辨你在用哪种？

证书 certificatecertificate the site's ID card — proof you reached the real site, checked by the browser for you 网站的身份证：证明「你连的真是这个网站」，浏览器替你查验

Check the address bar: a padlock means HTTPS, and clicking it shows the site's certificate. 看地址栏：有锁的就是 HTTPS，点开锁还能看到它的证书。

Now you know 现在你知道了

  • HTTPS is HTTP with one extra step: the content travels sealed. HTTPS 就是 HTTP 多一道工序：内容在路上是封着的。
  • Both take the same road; the only difference is whether others can read what passes. 两者走同一条路；差别只有路上那一段，别人看得见还是看不见。
  • Before typing a password or paying, look for the padlock in the address bar. 输密码、付钱之前，先看地址栏有没有那把锁。
