网页怎么来？

No networking background needed. This page explains it in about three minutes. 不需要任何网络基础。这一页大约 3 分钟讲明白。

What is this trip like? 这一趟像什么？

Press Enter and the browser places an order for you; four steps later it lands on your screen. 按下回车，浏览器就替你下了一单——四步之后，这份"餐"到了你屏幕上。

It's like…就像……

You order, the kitchen cooks, a rider delivers, you open the door and eat. A web page reaches your screen by the same four steps. 点一份外卖：下单，餐厅做，骑手送，开门就能吃。网页到你屏幕上，走的也是这四步。

1

Turn the name into an address 先把名字换成地址

DNSDNS the internet's shared phone book — a name goes in, a numeric address comes out 整个互联网共用的电话本：名字进去，数字地址出来

Computers don't use names, only numeric addresses; the browser asks DNS for that number first. 电脑记不住名字，只认数字地址；浏览器先去 DNS 查出这串数字。

2

Carry the request slip over 把请求单送过去

服务器 serverserver a computer that is always on, holding the page's files 一直开着的一台电脑，网页的文件都存在它那里

Address in hand, the browser carries a request slip to that server. 拿到地址，浏览器就把一张请求单送到那台服务器。

3

The files come back 文件送回来

The server packs the files — text, pictures, buttons — and sends them back to your computer. 服务器把文件打包发回——文字、图片、按钮，一路送回你的电脑。

4

Lay the page out 把页面摆出来

渲染 renderrender laying the delivered text and pictures onto the screen, piece by piece 把送来的文字和图片，按说明一件件摆到屏幕上

The browser renders the page from those files: skeleton first, then text and pictures. 浏览器照着文件把这一页渲染出来：先摆骨架，再放图文。

Now you know 现在你知道了

  • A page isn't simply "opened" — it is delivered to your screen from another computer. 网页不是"打开"的，是从另一台电脑送到你屏幕上的。
  • Four steps: look up the address, send the request slip, get the files back, render the page. 四步走完：先查地址，再送请求单，然后文件送回，最后渲染成页面。
  • Next time a page spins, you know it isn't broken — one of the four steps is waiting. 下次页面转圈，你知道它不是坏了——是四步里有一步还在等。
