# 水墨的材料:色值和理由

和 `assets/ink.css` 冲突时以 CSS 为准。写字用的颜色对纸和卡片的对比度 ≥ 4.5:1,`build.mjs` 每次构建都算一遍,不够就停。

## 1. 纸

| 变量 | 宣纸(浅) | 磁青纸(深) | 用在哪 | 为什么 |
|---|---|---|---|---|
| `--ink-paper` | `#f2ead8` | `#14213a` | 页面底、画的纸 | 宣纸是暖白,不是纯白;纯白底像打印稿 |
| `--ink-paper-2` | `#ebe1cb` | `#1a2944` | 第二种底 | 分段 |
| `--ink-card` | `#f8f3e7` | `#1d2d4a` | 卡片、图的舞台 | 比纸亮一点,不抢 |
| `--ink-rule` | `#d9ccb2` | `#2c3d5c` | 分隔线 | |

**深色版为什么是磁青纸配泥金,不是反相**:古人在深靛蓝的磁青纸上用泥金写经,深底金线本身是一种成立的画法。
反相会把墨变成白色、宣纸变成黑色,看起来像照片底片(graphite 在深色版上也是另画,见 `graphite-design/references/material.md` §1)。
深色版里墨叠墨用普通混合(`--ink-blend: normal`):金叠金不该变暗;浅色版用正片叠底,两笔交叠处更深,像真的墨。

## 2. 墨分五色

| 档 | 浅色 | 深色(泥金由亮到暗) | 用来 |
|---|---|---|---|
| 焦 `jiao` | `#1a1714` | `#f0d89a` | 最要紧的一笔、点睛、标题 |
| 浓 `nong` | `#2e2a26` | `#d9b96e` | 主体轮廓、正在讲的部分 |
| 重 `zhong` | `#4f4943` | `#b7995a` | 次要轮廓、次要的字 |
| 淡 `dan` | `#8a837a` | `#8a7650` | 远处、背景结构、基础设施 |
| 清 `qing` | `#c3bcb0` | `#5c5240` | 最远的山、雾、底纹 |

写字只用焦、浓、重三档(重档用于次要说明);淡、清两档对比度不够,不写字。

## 3. 颜料

| 颜料 | 浅色 | 深色 | 常干的事 | 写字用的深一档(浅 / 深) |
|---|---|---|---|---|
| 花青 `huaqing` | `#3e5f7a` | `#7fa6c4` | 水、远山、冷的东西、用户一侧 | `#34536c` / `#9dbdd6` |
| 赭石 `zheshi` | `#a8643a` | `#d08a5c` | 山石、秋、土、木 | `#8a4d27` / `#e0a67f` |
| 藤黄 `tenghuang` | `#d9a521` | `#e8c24a` | 光、判断节点、点亮 | 不写字 |
| 胭脂 `yanzhi` | `#9d2933` | `#d8606a` | 花、警告 | `#8e2430` / `#ec8d95` |
| 石青 `shiqing` | `#2f6f9f` | `#5f9fd0` | 青绿山水、重点(冷) | `#275f88` / `#8fbde3` |
| 石绿 `shilv` | `#3f8f74` | `#6cbf9c` | 青绿山水、通过、存储 | `#2a6852` / `#86d0b0` |
| 朱砂 `zhusha` | `#b8322a` | `#e0574a` | 印章、最重要的一处 | `#a32a23` / `#f08a7f` |
| 朱膘 `zhubiao` | `#d8673c` | `#ee8a5a` | 秋叶、正在发生的那一处 | 不写字 |
| 白粉 `baifen` | `#f3efe6` | `#f3efe6` | 雪、深色版的高光 | 不写字 |

深色版颜料提亮:在磁青纸上原值发闷,看不出「透明叠色」;提到和泥金同一亮度带。

**颜色预算**:同一种颜料在一张图里只代表一件事;颜料种数少于要讲的事。

## 4. 四种设色

| 设色 | 用哪些 | 适合 |
|---|---|---|
| 纯水墨 | 只有墨 + 印 | 技术图、冬景、武侠、诗词 |
| 浅绛 | 墨 + 淡赭石、淡花青 | 秋景、文档插图、界面点缀 |
| 青绿 | 墨 + 石青、石绿,颜色重 | 发布会、壁纸、夏景 |
| 没骨 / 彩墨 | 不勾墨线,颜色直接泼染 | 春景、动漫、海报 |

## 5. 字

| 用途 | 字体 | 许可 |
|---|---|---|
| 标题、画上题字 | 马善政楷书 Ma Shan Zheng | OFL 1.1 |
| 诗词题字、副标题 | 龙藏体 Long Cang | OFL 1.1 |
| 发布会大字、武侠 | 志莽行书 Zhi Mang Xing | OFL 1.1 |
| 图里的说明、批注 | 霞鹜文楷 GB 屏幕阅读版 | OFL 1.1 |
| 正文 | Noto Serif SC | OFL 1.1 |
| 代码、数字 | JetBrains Mono(关掉连字) | OFL 1.1 |

- 三个毛笔字体来自 google/fonts 仓库提交 `bd8f81ddb5c74d5c8897b36ad88b440266245103`(2026-10-11 查证许可证,设计书 §16.2),
  按实际写到的字切子集(`scripts/fonts.py`),许可证文件随子集放在 `assets/fonts/`。没有 Reserved Font Name,子集不用改名。
- 刘建毛草 Liu Jian Mao Cao 也是 OFL,但多数读者认不出草书字,不用。
- 毛笔字只用在标题和题字,**不当正文**:行书、草书小字号读不出来。
- 位图里不出现任何字:出图模型写的汉字常错。

## 6. 笔

| 参数 | 默认 | 为什么 |
|---|---|---|
| 飞白阈值 | 含墨量 < 0.42(口味 `dry` 调 0.32–0.52) | P0 小样 1 对照黄庭坚、米芾真迹定的;再高满纸飞白,再低几乎没有 |
| 笔毛根数 | 宽度 / 1.4,取 8–32 | 根数太少飞白成了几道粗条,太多看不出分叉 |
| 晕边 | 模糊 2.4px + 噪声位移 7;`wet > 0.9` 换 5.5px + 16 | 一笔落定后 0.6–1.5 秒内显出 |
| 打毛 | 整组噪声位移 2.2px | 去掉快一倍但边缘像矢量图(P0 小样 3),保留 |
| 每图笔数 | ≤ 800 | P0 小样 3 |
