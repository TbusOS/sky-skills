# 各类图的画法要点

图例源码在 `templates/src/`,每类挑一张读代码是最快的入门。下面只写每类最容易错的地方。

| 类 | 要点 | 例子 |
|---|---|---|
| 笔墨基础 | 一张图只讲一样:五色、三种笔、印、四种设色;字少,画多 | `00-basics.mjs` |
| 技术框图 | 框用 `Props.box`(四笔游丝,不是矩形);线一律 `dry: false`,飞白会把箭头断开;远淡近浓分层:基础设施用淡墨,正在讲的那层用浓墨 + `weight: 'heavy'` | `30-diagram.mjs` |
| 流程 | 判断用 `Props.decision`(藤黄淡彩);数据流用 `.flow` 虚线慢流,像水沿渠走;一色一事 | `30-diagram.mjs` |
| 代码大白话 | 左代码卡右画面,`B.window` 让高亮行和画面同一时刻变;代码卡在两种主题下都是深色 | `40-code.mjs` |
| 数学 / 算法 | 图里和说明里的数都由同一段代码算出(割圆术的 π、冒泡的交换次数);SVG 的 y 轴朝下,画曲线写成 `y = 底边 − 值` | `50-math.mjs` |
| 文档 / 网页 / UI | 水墨只做点缀:书法标题、墨痕分隔线、印章当状态;正文宋体,对比度 ≥ 4.5:1;按钮按下墨晕开(`ink.css` 的 `.ink-btn`) | `60-ui.mjs` |
| 数据图 | 墨条当柱、山脊线当折线;数由代码算;轴线用淡墨游丝 | `70-chart.mjs` |
| 诗词 | 诗竖排(`vertical: true`)题在留白处,龙藏体;一字一字写出;配一方印;出处写进说明 | `80-poetry.mjs` |
| 四季 / 山水 | 先铺淡墨远山(`order: 'wash-first'`),再画近景;雾、水用 `B.animate(…, { repeat: 'infinite' })`,周期 ≥ 6 秒 | `82-seasons.mjs`、`84-landscape.mjs` |
| 武侠 / 太极 | 剪影一两笔;刀光用低含墨量的长笔出飞白;太极阴阳鱼用 `Props.enso` 一笔画出 | `86-wuxia.mjs` |
| 电影 / 短剧 | 9:16 封面留出上下安全区(上 12%、下 18% 不放主体);分镜格之间留白 | `88-film.mjs` |
| 壁纸 | 桌面 16:10 中间偏下留给图标;手机竖屏上 1/4 留给时间 | `90-wallpaper.mjs` |
| 发布会 | 一屏一句话;泼墨 `B.splash` 揭幕,标题用志莽行书一笔写出 | `92-launch.mjs` |
| 越用越懂你 | 图里的曲线在构建时真跑 `design-taste`(模拟读者),不手写 | `95-taste.mjs` |
