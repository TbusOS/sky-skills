# atelier · SVG 图示工艺

## §1 图放什么

应用界面里的图不是插画,是**读者当下要回答的那个问题的答案**。
问不出问题的图不要画。

## §2 纹理进 CSS,信息进 SVG

booking 页的航线图:点阵底是 CSS `radial-gradient` + `background-size`,
SVG 里**只有**两个机场、一条大圆弧、三个标签。

**为什么**:点阵是纹理不是数据。放进 CSS 之后 SVG 只剩下屏幕阅读器该听到的东西 ——
所以 `aria-label` 是一句话,而不是四百个坐标。同时 SVG 从 400 个 `<circle>` 降到 6 个元素。

## §3 示意图要承认自己是示意图

航线图没有海岸线,figcaption 明写 **"示意图,不是航行图"**。

一张 80% 准确的地图会邀请读者去量它;一张说清自己是什么的图,给出同样的信息
(方向、距离、两个端点)而不撒谎。

## §4 硬性尺寸

- SVG 文字源尺寸 **≥11px**,渲染缩放 ≥0.82(低于 9px 渲染值被闸拦)。
- 内容必须**铺满画布** —— 内容只占宽度 56% 会被 `svg-letterbox` 拦。
  收紧 viewBox 到贴合内容(边距 ≤24px),或把内容摊开。
- 每个 `<svg role="img">` 必须有 `aria-label`,写**结论**不写形状:
  "评分从 2025 一季度的 71 升到 2026 三季度的 92,七个周期都高于团队中位数",
  不是"一条上升的折线"。

## §5 绘制顺序 = 图层顺序

半透明面积填充画在文字之后,会**盖住文字**。

真实踩坑:detail 页的 "median 71" 标签写在面积路径之前,被 30% alpha 的渐变盖成 100% 重叠,
`svg-shape-over-text` 闸抓到。修法是把标签移到所有填充之后绘制。

**规矩**:所有 `<text>` 放在 SVG 的最后。

## §6 颜色

图内颜色走 `data-display.md` §1 的同一套:一条渐变 + 中性轨道 + 参照灰虚线。
`<defs>` 里的 `linearGradient` id 加 `atl-` 前缀避免多图冲突。

图内**不要**用 `currentColor` 取文字色 —— 双主题下会跟着翻,但轨道不会,对比度会崩。
用 token:`fill="var(--atl-ink)"` / `var(--atl-ink-2)` / `var(--atl-ink-3)`。
