# atelier · 品位边界

暖玻璃和"又一个 admin 模板"之间只隔十来条线。每条都写了**判据**,不是口号。

## §1 图标

| ✅ | ❌ |
|---|---|
| 实心渐变球 `.atl-orb`,白色图形在里面 | 线性图标 + 1px 圆环 |
| 三档尺寸(34 / 46 / 58) | 每个位置一个新尺寸 |
| 列表行用 `--soft` 淡底 | 一屏里每行都上满渐变 |

**判据**:把页面缩到 25% 看缩略图。如果分不清这是 atelier 还是任意一个 Tailwind admin kit,
问题一定出在图标。

## §2 侧栏

- 选中态是**白色 pill + 轻投影**,不是彩色块。彩色块会跟数据抢注意力,而侧栏是家具。
- 分组标签(`MAIN MENU` / `TEAM`)10px、字距 0.16em、大写。分组是给扫读的,不是给读的。
- 徽标数字用 `--atl-accent-soft` 淡底 + `--atl-accent-ink` 文字。**不要**用实心玫红圆点 —— 那是"未读"的语义,不是"有 7 个"。

## §3 颜色

- **一族强调色**:珊瑚 + 玫红,永远一起出现,通常在渐变里。
- 第三个色(琥珀 `--atl-amber`)**只用于分类构成**(饼图切片这类),不用于序列。
- 判断色(`--atl-up` / `--atl-down` / `--atl-warn`)是**结论**,不是系列色。
  一张图要么用财务涨跌轴,要么用状态轴,不能两个都用。
- ❌ 彩虹系列色。那是通用后台模板的标志,和 §1 同一个失败。

## §4 渐变

> **渐变永远不承载文字。**

实测:白字压在珊瑚端 `#F5854F` 是 **2.5:1**,连大字号 AA(3.0)都不过;
压在玫红端 `#DD4F92` 是 3.8:1,只够大字号。按钮是小字,所以:

- 实心强调按钮 → `--atl-accent-ink`(`#B83370`,白字 **5.6:1**)
- 主按钮 → 默认 `.atl-btn`,近黑底(参考原作的 "Select Flight" 就是近黑的)
- 渐变只出现在:圆球、柱填充、进度条填充、品牌标记、滑块填充

## §5 布局

- `.atl-page` 1280 是工作档;侧栏 244 + 4 列 KPI 时**必须**升到 `--wide` 1440。
- **没有 hero 档**。这个 skill 画应用,应用没有 hero。想做 hero 说明选错 skill 了。
- 卡片间距 `--space-5`(20px),卡内 `--space-5`。应用界面比文档紧,但不能紧到黏。
- 空白区:侧栏底部的大片留白是 `margin-top:auto` 的正常结果,不要填东西。
  卡片内部的大片留白要填 —— 填**信息**(一行说明这张图为什么这样读),不填装饰。

## §6 文字

- 中文字体栈必须带 `Noto Sans SC`,否则 CJK 落到系统默认,和 Plus Jakarta Sans 的
  字重完全对不齐。
- 中文正文里的标点用**全角**,`，；：` 不用 `,;:` —— verify.py 会拦。
- 数字一律 `font-variant-numeric: tabular-nums`。表格里的数字不等宽,列就对不齐。
- ❌ 斜体。这套语言里没有斜体的位置。

## §7 数据纪律

- 终值写在 markup,`data-count-to` / `data-grow` 只做动画。**JS 永远不发明数字。**
- 分段控件 / 筛选框 / 滑块**是装饰**。切换即改数 = 编数据。canonical 页不能显示查不到来源的数据。
- **反常的数字必须当场解释**:
  - "6 月 31%" → 因为评估周期错过校准窗口,34 份落到 7 月
  - "2 次以上中转 $245+ 比 1 次中转贵" → 因为唯一那条接续要分开出票
  - "2024 年那一跳" → 是职级带变更不是普调

  一个不解释自己的异常值,会被读成 bug,然后引出一场错误的会。

## §8 空状态与错误态

- 错误信息要**说清下一步怎么办**,不是"操作失败"。
  反面:`Invalid credentials`。正面:`该邮箱不在这个工作区里 —— Loka 在 loka.example/studio
  找到了它,可以去那个工作区,或者请 Carla 把它邀请到这里。`
- 已知的约束要**在失败之前说**(雅加达实体必须走 SSO ⇒ 写在按钮上方,不是第三次失败之后)。

## §9 破坏性操作

- 要能到达,但不能容易:独立的导航目的地 + 红色调面板 + 确认输入框 + 禁用按钮。
- 删除按钮用 **ghost 样式**,不用实心红块。**实心红块是设置页上最常被点的东西。**

## §10 交互

- 每个行为都是 `data-*` 属性。**页面不写 atelier JS。**
  一个无法用属性表达的行为,不该进 canonical。
- 所有面板的 markup **都写在页面里**,用 `[hidden]` 切换。JS 关掉也读得全。
- 冻结契约:`?freeze=1` 或 `data-motion="off"` 时,所有动画第一帧就到终态,
  而终态永远是 markup 里已经写好的东西。

## §10.5 颜色一律按"最难的底"取值

判断色(`--atl-up` / `--down` / `--warn`)最常出现在**自己的 12% 淡底 chip 上**,
那比卡面更难。旧值 `#1F8A5B` 在卡上 4.20、在自己 chip 上只有 **3.61**。
取值时永远按最难的那个底算,不是按白底算。

墨色同理:页面级文字(页脚、kicker)落在**壁纸**上,比卡面难。

## §11 最容易犯的几个错

1. **把 `<span>` 当块用。** `.atl-rank__name`、`.atl-timeline__dot` 这些槽位在 canonical
   里是 `<span>`,inline 盒子**静默忽略** width / height / 竖直 margin。症状不是报错,
   是 `16:45YIA` 粘成一行、9px 的时间轴圆点渲染成 2px 竖条。CSS 里那些 `display:block`
   删一个就坏,而且哪里都不报错。
2. **暗区域忘了 `.atl-inksurface`。** 手写 `background: var(--atl-ink-card-bg)`,
   `.atl-muted` 会继续用亮色主题的灰,在深色上几乎不可见。渲染对比度闸抓不到。
3. **两张暗卡。** 见 `atelier-material.md` §6。
4. **ink-3 用出卡外。** 壁纸重校(加浓)后,`--atl-ink-3` 只在卡上(0.80+)过 AA;
   壳(0.32)、rail(合成 0.456)、裸壁纸上一律 ink-2 起。材质 v3 把壳纱降到 0.32 之后,
   `.atl-tab` 的未选中项(原本 ink-3)当场掉到 **3.99:1** —— 这条规矩不是理论,
   壳越透它越咬人。裸壁纸上的玫红用
   `--atl-accent-ink-deep` —— **axe 管不了渐变底**(标 incomplete 不标 violation),
   这条只能靠自觉。
5. **小字号控件压在 `--atl-track` 上还用次级墨。** `--atl-track` 只有 11% 深度,
   它盖不住裸壁纸,所以那上面的地基跟裸壁纸一样难。语言切换钮(11px mono)用 ink-2
   量到 **4.3:1**,差一点点过不了 AA;改成 `--atl-ink` 之后 5 个 canonical 的渲染
   contrast warning 从 1 条清到 0 条。**选中态靠白 pill 区分,不靠未选中项变浅** ——
   想用浅色表达"未选中"就会掉到这个坑里。修法是加深墨色,不是降 alpha
   (`design-tokens.md`「墨色为什么是实心值」)。
6. **壁纸调淡"求雅"。** 玻璃感 = 壁纸饱和度 × 明暗跨度 × 壳透明度。
   把壁纸调到 S<20 / 跨度 <10,玻璃立即退化成米白纸 —— 三闸 + axe 全绿也救不了,
   这是纯品位盲区,发现方式是**对参考板采样**(见 material.md §1)。

## §12 交付前四闸

```bash
bin/design-review --skill=atelier <页面>.html          # 结构 + 渲染 + 可达性 + 截图
bin/design-review --skill=atelier --pixel <页面>.html  # 再加像素回归(需已有基线)
```

第三闸是 **axe-core**。atelier 的 5 个 canonical + 2 个 demo 页目前 **7/7 零 violation**,
这是这个 skill 的验收线 —— 新页面掉出这条线就是退步,不是"axe 太严"。
