# atelier-design · signin canonical

门口那一屏。最短的一页,也最容易做成模板。

## 让这一页成立的 5 个决策

### 1. 分栏壳,不是居中方框
一块壳切成表单 + 暗面板,不是一个 400px 的卡片浮在正中。
**为什么**:居中方框是这套美学里最像模板的一屏 —— 每个 glassmorphism kit 都送一个。
切开壳,既让这个 skill 的锚点动作(每屏恰好一张暗面)有活干,也让这一页有话可说。

### 2. 错误信息要给下一步
"该邮箱不在这个工作区里 —— Loka 在 loka.example/studio 找到了它,
可以去那个工作区,或者请 Carla Sandoval 把它邀请到这里。"
**为什么**:`Invalid credentials` 是对一个这里没人问的安全问题的正确回答 ——
邮箱存在、用户拥有它,真正的问题只是走哪扇门。
点名另一个工作区和有权处理的人,把死胡同变成下一步。

### 3. 约束在失败之前说
雅加达实体必须走 SSO,写在按钮上方。
**为什么**:这是产品知道而用户不知道的规则,最便宜的说出口的位置在按钮上方,
不是第三次失败之后。

### 4. 给进去的理由,不是一张图库照片
暗面板放三个数:6 份评估待打分、3 场面试、1 项调薪未录入。
**为什么**:这是用户手上信息最少的一屏,而暗面板是黄金位置。三个数回答"为什么现在进去"。
说明里承认它们可能已过期,这是把它们放在登录前的诚实代价。

### 5. 这一页靠圆球扛品牌
暗面板里三个渐变圆球。
**为什么**:这页没有 KPI 行、没有图表、没有进度条 —— 不放圆球,它几乎不含玫红,
会被品牌闸拦,而且拦得对:那时它已经不像这个 skill 了。

## 已知取舍
错误横幅是加载即显示的(登录页静息态没有错误,但错误态才是这屏所有设计决策的所在);
登录前展示计数是真实的隐私取舍(设备本地缓存可辩护,服务端查询不可);
密码框里是字面的圆点不是真掩码;没有注册入口(这是邀请制工作区产品)。
