# atelier-design · dashboard canonical

Loka 的人力控制台。生成任何 atelier 仪表盘前先读这份,HTML 是参考实现。

## 让这一页成立的 7 个决策

### 1. 整个应用在一块玻璃里
rail、顶栏、所有面板都在一个 `.atl-app` 里,而不是"玻璃侧栏 + 几张浮在壁纸上的卡"。
**为什么**:壁纸是房间,应用是房间里的一扇窗。卡片直接飘在渐变上会把产品读成营销 hero,
读者失去了"工具从哪里开始"的边界。

### 2. 玻璃是外壳,不透明度是数据
外壳 0.52 → 数据卡 0.80 → 表格卡 0.94。
**为什么**:数字压在会动的渐变上,读者会不自觉读两遍。外壳可以透,因为它是家具;
任何承载数字的表面都要往不透明走。

### 3. 渐变圆球,不是线性图标
实心珊瑚→玫红圆球 + 白色图形。
**为什么**:这是整套语言真正的签名。原作者的底子是渐变图标集,
而"线性图标 + 1px 圆环"是通用 admin 模板的标志 —— 复刻错这一笔,
出来的东西和任何一个 Tailwind admin kit 没有区别。

### 4. 只有一张暗卡
面试队列那一张。
**为什么**:亮底页面上暗卡是视线第一落点;两张就分裂了落点,两张都不赢。
暗色主题下它翻成奶油 —— 这一笔是"一张卡打断明暗节奏",不是"一张卡是黑的"。

### 5. markup 就是终态
KPI 终值写在 markup 里,`data-count-to` 镜像它;柱高写在内联 style 里,`data-grow` 只做动画。
**为什么**:冻结契约让静态 markup 成为权威渲染,审查闸、无 JS 读者、确定性截图看到的是同一个页面。
动画是糖,页面本身已经是对的。

### 6. 面板全部写在页面里
每个侧栏目的地的 markup 都在,用 `[hidden]` 切换,不 fetch 不构建。
**为什么**:canonical 页必须在没有 JS 时可读,评审者必须不运行任何东西就能看到第二个面板有什么。

### 7. 6 月那根柱子要解释
31% 那根旁边写明:研发的评估周期错过校准窗口,34 份落到 7 月,6 月和 7 月要合起来看。
**为什么**:控制台的职责是阻止读者误读它。**一个不解释的低谷,是"开错一场会"最常见的单一来源。**
