# atelier-design · booking canonical

Maburo 机票搜索。证明这个 skill 不只会做仪表盘。

## 让这一页成立的 7 个决策

### 1. 没有侧栏的壳
`.atl-app--full`,一块玻璃,零导航栏。
**为什么**:搜索页的导航就是搜索栏本身;塞一条目的地列表会跟用户唯一想用的控件抢注意力。
证明壳在没有 rail 时也成立,是这个 skill 不至于产出"七个都是仪表盘"的关键。

### 2. 第三行预先展开
上面两行折叠,第三行渲染成打开态。
**为什么**:所有设计风险都在展开态里(卡里套标签页,标签页里套时间轴和图)。
把最难的布局藏在一次点击后面 = 截图闸永远看不到它,这页就不可评审。

### 3. 筛选项要带上自己的理由
每组筛选下面一句话,解释反直觉的数字。
**为什么**:"2 次以上中转 $245+" 看起来像数据错误,直到你知道唯一那条接续要经吉隆坡分开出票。
一个让用户意外又不解释自己的筛选器,会被当成 bug。

### 4. 时区差要写出来
明写"2 小时 22 分的飞行在钟面上看起来是 3 小时 45 分"。
**为什么**:这是所有出行产品里最常见的一次误读,而修它只要一行字。

### 5. 示意图,不是地图
大圆弧压在 CSS 点阵上,figcaption 明写"示意图,不是航行图"。
**为什么**:一张 80% 准确的地图会邀请读者去量它;一张说清自己是什么的图,
给出同样的信息(方向、距离、两个端点)而不撒谎。顺带把 SVG 从 400 个圆点降到 6 个元素。

### 6. 点阵进 CSS
`radial-gradient` + `background-size`,不是生成的 `<circle>`。
**为什么**:点阵是纹理不是数据。放进 CSS 之后 SVG 只剩屏幕阅读器该听到的东西,
所以 `aria-label` 是一句话而不是一串坐标。

### 7. "最便宜"要论证,不是贴标签
一张暗卡讲清为什么这班最便宜,**以及什么条件下不是**(有人要 30kg 行李时 Garuda 总价更低)。
**为什么**:徽章是断言,段落是论证,而且它点明了推荐翻转的条件。

## 已知取舍
筛选框和滑块不重新查询;滑块是 markup 不是真 range(不可键盘操作);
只有一行带完整详情卡;航线图没有海岸线。
