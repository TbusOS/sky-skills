# 画调用路径:什么时候用 ASCII 树,以及它唯一会坏的方式

内核答案里最常要画的东西是**一条调用链**:`sys_read` 到底怎么走到 `virtqueue_notify`。
这份文件只回答两个问题:什么时候该用 ASCII 树、它会怎么坏。

## §1 什么时候用 ASCII 树

| 内容 | 用什么 | 为什么 |
|---|---|---|
| **30 层以上、每层都是纯 ASCII 的 C 函数名** | **ASCII 树** | 缩进天然表达深度,没有布局约束,而且能整段复制去 `grep`。画成 SVG 流程图必然不可读:30 个节点纵向排开高度冲破一屏好几倍,压到放得下则字号掉到 6px |
| 5-8 步、要标错误分支和 cleanup | SVG 流程图 | 分支和汇合点靠位置说话,树的缩进表达不了"两条路汇到同一个出口" |
| 跨层的时序(谁先谁后、谁在等谁) | SVG 时序图 | 树没有时间轴 |
| 状态机 | SVG 状态图 | 树没有环 |

判据是形状,不是长度:**"深度 + 纯标识符"用树,别的都不用。**

## §2 格式

```
sys_read
   -> ksys_read
      -> vfs_read
         -> file->f_op->read_iter: ext4_file_read_iter
            |
            | EXT4
            V
            -> generic_file_read_iter
               -> filemap_read
                  -> folio_wait_bit             (blocks here)
                  |<---------------------------- resumes at this depth
                  -> copy_folio_to_iter
```

- **深度只用缩进表达**,固定 3 空格一层;`->` 开头表示"调用"。
- **跨子系统处插三行** `|` / `| SUBSYS` / `V` —— 这是全树唯一的分层信号,替代流程图里的泳道。
- **返回 / 唤醒用 `<---`**,画在它真正落回的那一层的缩进位置上。
  横线的**长度没有意义,落点的缩进有意义** —— 那是读者判断"回到哪一层"的唯一依据。
- **函数名后可跟 `: 实际实现`**(`file->f_op->read_iter: ext4_file_read_iter`):
  写出间接调用这一跳最终落到谁身上,是这类图最值钱的信息,也是流程图最难画的部分。

## §3 它唯一会坏的方式:列错位

这棵树的全部信息都编码在**列**里 —— 每一帧的深度就是它的缩进。
于是所有的坏法都是同一种坏法:

| 坏法 | 后果 |
|---|---|
| **树体里出现一个非 ASCII 字符** | 中文一个字在某些字体里占两格、在另一些里占一格。它下面每一行的列都对不上了,而**看起来仍然整齐** —— 这是最难发现的一种 |
| 某一帧缩进不在步长上 | 这一帧没有读者能说得出的深度 |
| `<---` 的起始列没有对应的帧 | 那条箭头"返回到了不存在的地方" |
| 单行超过容器宽度 | 折行,折下来的那半截读作**列 0 的新帧** |

**所以中文注释一律写在树外面**(答案正文或 figcaption 里),树里只留 ASCII。
`(blocks here)` 这种短英文标注可以留在树里,但它也占列 —— 长了就挪出去。

## §4 闸

```bash
scripts/check_call_tree.py <file>          # exit 1 = 有发现
scripts/check_call_tree.py --selftest      # 四类缺陷各一个探针,外加一个干净树校准假阳
```

- 只认**行首**的 `-> 标识符` 当调用帧 —— 这一条是它不去骚扰 SVG / HTML / C 代码块的原因
  (`-->` 结束注释、`file->f_op` 在行中,都带 `->` 但都不开头)。
  上线前对全仓 skill 文档跑过一遍:**0 假阳**。
- 四类检查:`non-ascii-in-tree` / `ragged-indent` / `dangling-return` / `line-too-wide`,
  外加超过 60 行的 `tree-too-long`(折进 `<details>`)。
- 判断调用链**本身对不对**不归它管 —— 那是 `fact_gate.mjs` 和人的事。这个闸只管列对不对得上。
