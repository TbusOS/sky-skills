# 材料:五样东西的具体值和理由

色值的权威在 `assets/graphite.css` 第 1 节;本文件和它冲突时以 CSS 为准。

## 1 纸

| | 浅色 | 深色 | 用在哪 |
|---|---|---|---|
| `--g-paper` | `#f6efe2` | `#131925` | 页面底、插画的纸 |
| `--g-paper-2` | `#efe6d4` | `#19202d` | 第二种底(隔开的段落、字幕条) |
| `--g-card` | `#fbf7ee` | `#1c2331` | 卡片、图的舞台 |
| `--g-rule` | `#dccfb8` | `#2b3342` | 分隔线、虚线框 |

- **为什么不是纯白**:铅笔线放在纯白上,像扫描的打印稿;暖纸是这套画风的第一眼印象。
- **为什么深色是藏青不是黑**:ai-doc 的夜间插画用 `#141a26` 附近的藏青纸,粉笔线在上面像夜里的黑板;纯黑上的浅线发硬。
- **深色版要另画**:代码画的图换变量就行;位图要让出图模型另出一张(把浅色图当构图参考)。
  ai-doc 试过把浅色图反相:夜空变成白天的浅蓝、头发变白、亮着的屏幕变成暗褐色,意思全反了。
- 纸面颗粒:页面背景是一张 180×180 的噪点小图(`graphite.css` 里 `.g-page`),单独的 SVG 里是 `#g-tooth` 滤镜。

## 2 石墨线

| | 浅色 | 深色 |
|---|---|---|
| `--g-line` 主线 | `#39332c` 深灰褐 | `#ddd5c6` 粉笔 |
| `--g-line-soft` 次要线、阴影 | `#7c7266` | `#8f96a3` |
| `--g-lw` 主线宽 | 2.1px | 同 |

手画感来自四处「不准」,`sketch.js` 全做了,自己画时也照这几条:

1. 两端各冲出去 0–4px(转角处两条线交叉一点点);
2. 中间有一点弓(长度的 1.2%,最多 2.4px);
3. 画一个圈时多画 12% 再停笔,起点和终点叠在一起,不严丝合缝;
4. 每条线画两遍:一道主线,一道更细、短一点的第二笔,两头看着像是收笔变细了。

再加一层铅笔滤镜(`Sketch.filters()`):低频扭曲让直线有一点点弯,高频颗粒在线上打出小缺口。
**字不进滤镜**,不然手写字会被颗粒啃得发虚。

## 3 彩铅

十支,每支浅、深两个值;拿来写字时用 `-ink` 那一档(在纸和卡片上对比度 ≥ 4.5:1)。

| 彩铅 | 浅 | 深 | 常干的事 |
|---|---|---|---|
| blue | `#3d6db5` | `#7ea6e6` | 夜空、用户一侧、冷的东西 |
| sky | `#7fb2e0` | `#9cc8ee` | 白天的天、屏幕 |
| orange | `#e2772c` | `#f39a52` | 重点、正在发生的那一处 |
| green | `#4c9a5b` | `#7cc690` | 保留、通过、存储、植物 |
| red | `#c94a3c` | `#ef7d70` | 失败、警告 |
| yellow | `#e9b94a` | `#f0d070` | 光、判断节点、荧光笔 |
| wood | `#c79d6e` | `#b48d63` | 家具、木头 |
| pink | `#e8968f` | `#e3a29c` | 脸颊 |
| grey | `#9b9284` | `#8a909c` | 丢弃、基础设施、机器人的身体 |
| violet | `#8a74c4` | `#b2a2ea` | 第五种语义(步长、NPU……) |

另有三支「意思不随夜晚改变」的:`skin`(浅 `#f0c9a2` / 深 `#e6c8a8`,夜里脸还是浅的)、
`hair`(夜里是深的)、`--g-face`(五官的线,画在皮肤上,两种主题都深)。
2026-10-10 第一版用木头色当皮肤、五官用粉笔色,深色模式下人物成了一团黑脸,看不见眼睛。

怎么涂:

- 一层很淡的底色(浅色 20%、深色 24% 不透明)+ 一层来回的排线(间距约 3.7px,线宽 1.9px,52%)。
- 排线的行距随机在 0.7–1.3 倍之间,两端不贴边,随机缩进 0.5–4px。
- **颜色预算**:一张图里颜色的种类少于要讲的事;同一种颜色在一张图里只代表一件事。
  ai-doc 那张卧室图:蓝色只在窗户、橙色只在屏幕。被子第一版是蓝的,跟窗外的夜抢眼,改成了米白。
- 大片纸面空着。插画顶部留 15–18% 空纸,放标题或叠数据卡。

## 4 字

| 用途 | 字体 |
|---|---|
| 标题、图里的说明、批注 | `--g-hand`:霞鹜文楷 GB 屏幕阅读版(OFL 1.1),拉丁字母也用它 |
| 正文 | `--g-body`:Lora + Noto Serif SC |
| 代码、数字、坐标刻度 | `--g-mono`:JetBrains Mono,关掉连字(`<=` 不能变成 ≤) |
| 小标签 | `--g-sans`:Noto Sans SC |

- 插画本身不写字。出图模型写的字常是错的;字由网页叠上去,还能切换语言。
- 图里的字最小 13px。图在手机上会缩,小于 13 就得把图框做得很宽才能保住 9px。
- 深色终端卡(`--g-term-bg`)在两种主题里都是深的,里面的字用 `--g-term-*` 那一组。

## 5 先线后色,一笔一笔

- **一支笔**:同一时间只画一样东西,每一笔用的时间和它的长度成正比(恒速的笔)。
- **故事顺序**:场景 → 主角 → 动作 → 结果(srt-whiteboard-animation 的标注规则)。不是从左到右扫。
- **先线后色**:每组里勾线占 2/3 时间,上色占 1/3。
- **一个时钟**:画面、代码高亮、计数、字幕都从同一个时间算出来。
- **关掉动画也完整**:`prefers-reduced-motion` 下所有动画停掉,显示画好的样子;只在中途出现的东西(计数的中间值、移动的小点)带 `tmp` 类,这时隐藏。
