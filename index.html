sky-skills is a folder of skills for Claude Code: kernel engineering, technical PDFs, video and documents, and ten design voices that each render HTML their own way. The generators never grade their own work — a separate reviewer reads only the rendered page, and the numbers on this page are checked against the disk. sky-skills 是一组给 Claude Code 用的 skill:内核开发、读技术 PDF、做视频和文档,还有十个各自渲染 HTML 的设计风格。生成的一方从不给自己打分 —— 另有一个评审只看渲染出来的页面;这一页上的数字,也由脚本对着磁盘核对。

The harness评审回路

Generators never grade their own work.生成的一方,从不给自己打分。

The ten design skills generate. design-review lives in another folder and sees only the rendered page. Every miss it learns from becomes a known-bug row and a new check, so the same bug is not missed twice. The idea comes from Anthropic's harness design for long-running apps.十个设计 skill 负责生成。design-review 放在另一个目录,只看渲染出来的页面。它每漏掉一次,就多一条 known-bug 和一项新检查,同一个问题不会漏第二次。思路来自 Anthropic 的 harness design for long-running apps。

Every answer carries a [CLAIMS] block. fact-gate looks each symbol up in real 6.1 and 7.0 trees; then seven critics score the answer, and a safety failure vetoes it.linux-kernel-dev 写、审、调驱动、Kconfig、设备树和补丁,覆盖 44 个子系统。每个回答都带一段 [CLAIMS]。fact-gate 到真实的 6.1 和 7.0 源码树里逐个查符号;再由七个评审打分,安全一项不过就整份否决。

Install安装

Three ways. Pick your fit.三种装法,挑一种。

A skill is a folder. Four are a lone SKILL.md (skills-sync, design-planner, design-evolve, wechat-video-publisher); the rest carry scripts/, references/ or templates/ and must be installed as the whole directory, or their scripts will not run. Restart Claude Code afterwards — skills load by their TRIGGER words, so you never call one by name.一个 skill 就是一个文件夹。只有四个是单独一份 SKILL.md(skills-sync、design-planner、design-evolve、wechat-video-publisher);其余都带 scripts/、references/ 或 templates/,必须整个目录装,不然脚本跑不起来。装完重启 Claude Code —— skill 按 TRIGGER 关键词自动加载,不用点名。

Concept概念
What is a Claude Code skill?Claude Code skill 是什么?

        
A folder with a SKILL.md whose TRIGGER words tell Claude when to load it, plus any scripts, templates and references it needs. Written once, applied every time it is relevant.一个带 SKILL.md 的文件夹:TRIGGER 关键词告诉 Claude 什么时候加载它,再加上需要的脚本、模板和参考资料。写一次,每次用得上时自动生效。
