谁来画:择优录取Who paints: best of two

同一题,两边各画一版Same subject, two painters

字、数、连线要准的图一律代码画。艺术类画面让代码和出图模型各画一版,按四条选:五样都在没有、场景目标达到没有、动起来好不好看、能不能换主题和语言。结果:位图赢在质感,代码赢在要逐字写出的诗、要准的片名、会动的钟声和刀光 —— 所以多数题最好是叠用,位图打底,代码写字、盖印、加动画。红框是选中的那一版。Anything with exact words, numbers or lines is code. For pictures, code and the image model each paint one, judged on four things: all five fixed elements present, the scene’s goal met, how it moves, whether it can switch theme and language. The bitmaps win on texture; code wins on poems written character by character, exact titles and moving bells and blades — so most subjects are best layered: bitmap underneath, code writes, stamps and animates. The red frame marks the pick.
