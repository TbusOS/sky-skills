You ask AI for help every day — it forgets how you work 你每天让 AI 帮忙，
可它记不住你的做事方式

The thing that makes it remember is called an Agent Skill. No background needed — about three minutes. 帮它记住的那样东西，叫 Agent Skill。零基础，这一页大约 3 分钟讲明白。

What is a skill? Skill 是什么？

Agent SkillAgent Skill instructions an AI assistant reads before doing that kind of work 一份写给 AI 助手的做事说明，存成文件，做那类事之前它先读

Your way of working, written down — that is a skill. Skill 就是把你的做事方式写下来，助手动手之前先读。

It's like…就像……

The handbook a company hands a new hire: rules and examples inside. Read it first, and nobody has to walk you through. 公司发给新同事的入职手册：规矩和范例都写在里面。先读它，就不用老员工天天带。

What changes with one? 有没有它，差在哪？

Without a skill, the method lives only in your head — you re-explain it every time. With one, the assistant reads the handbook first and works your way, every time. 没有 skill，做法只在你嘴里，每次都要重新交代。有了 skill，它动手前先读手册，照同一套方式做。

What's in this repository? 这个仓库里有什么？

仓库 repositoryrepository the shared place these instruction files live — everyone pulls the same copy 集中存放这些说明文件的地方，所有人取到的是同一份

This repository holds all 22 skills — each one a handbook. 9 design skills teach it to draw pages — under half the shelf. 这个仓库放着全部 22 个 skill——每个都是一本手册。其中 9 个设计 skill 教它画页面，占不到一半。

How do the machine checks work? 机械检查怎么工作？

A machine check is a program proofreading for you: every finished page, rule by rule. 机械检查就是程序替你核对：每页做完，逐条对照手册里的规矩。

1

A finished page goes in first 做完一页，先交给程序

2

Checked line by line 对着清单逐条核对

3

One miss sends it back 一条不过就打回重改

Now you know 现在你知道了

  • A skill is your working method written down; the assistant reads it before starting. Skill 是写下来的做事说明，助手动手之前先读它。
  • Explain a job once, and it comes out the same shape every time. 同一类事讲一次就够，做出来每次是同一个样子。
  • Every page passes the machine checks before it ships; one miss sends it back. 每页交付前先过机械检查，一条不过就打回重改。

The same drawing language also covers hardware and the kernel: seven technical primers, from one row of switches to a whole chip. 同一套画法也讲硬件和内核，收在技术图解七页里，从一排开关讲到一颗芯片。
